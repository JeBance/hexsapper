# HexSapper Icon Generator

To generate the PWA icons, open `generate-icons.html` in a web browser and click "Download All Icons".

Alternatively, you can use any image editor to create PNG icons in these sizes:
- 72x72
- 96x96
- 128x128
- 144x144
- 152x152
- 192x192
- 384x384
- 512x512

Save them as `icon-{size}.png` in the `icons/` folder.

## Quick Alternative

You can also use the SVG icon (`icons/icon.svg`) directly for some browsers, or use an online tool to convert SVG to PNG.
